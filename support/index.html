Getting your Airthings API key

LuftDings uses your own free Airthings API key to read your data (Bring Your Own API Key). Every Airthings account includes one at no extra cost. To create it:

  1. Sign in to your Airthings account at dashboard.airthings.com.
  2. Open the Integrations / API section and create a new API client.
  3. Choose the client-credentials flow (machine-to-machine).
  4. Copy the Client ID and Client Secret (use “Display secret” to reveal it).
  5. In LuftDings, paste both values on the setup screen and tap connect.

Your credentials are stored only in the iOS Keychain on your device and are sent directly to Airthings — never to us. See the Privacy Policy.

Adding a widget

  1. Touch and hold an empty area of your Home Screen until the apps jiggle.
  2. Tap the + in the top corner, search for LuftDings.
  3. Pick a size (small, medium, or large), then tap Add Widget.
  4. Long-press the widget and choose Edit Widget to select which device and sensors it shows.

Frequently asked questions

Which Airthings devices are supported?

Any device available through the Airthings Cloud API, including the WiFi-based View series. PM2.5 is shown on devices that report it, such as the View Plus.

Why do I need an API key?

Airthings’ official app has no iOS widgets and no public per-user login for third-party apps. LuftDings reads your data through your own API key instead, so your data stays under your control.

How often do the widgets update?

iOS decides when widgets refresh — typically every 15–60 minutes — so readings are not real-time. LuftDings always shows a “last updated” time, and it refreshes gently to stay within Airthings’ API rate limit (120 requests per hour).

The widget isn’t updating.

Open the LuftDings app once to fetch fresh data and refresh the widgets. Make sure the app has network access and that your API credentials are still valid in your Airthings account.

I get an authentication error.

Re-check your Client ID and Secret in the app, and confirm the API client still exists in your Airthings dashboard. Re-entering the credentials usually resolves it.

Is my data private?

Yes. LuftDings has no server and collects nothing. Everything runs on your device. Details are in the Privacy Policy.
